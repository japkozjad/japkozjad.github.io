My official website. Go to https://japkozjad.github.io.

## AI Disclosure
I used an artificial intelligence in following tasks:
- **Lore and Character Cards translation**:
	I was writing most sentences in Polish language, then the text was translated using [DeepL](https://deepl.com).
- **Bot Responses (`assets/bot-responses.json`)**:
	LLM's task was analyze of `lore.md` and Character Cards from `characters/<...>.html`, then making a JSON "responses" keys based on content from those files.
- **Help with JavaScript**:
  Files like `ai-chatbot.js`, `compontents.js` (`function characterSlideshow()`, `function lorePage()` and `function packs()`) were created with help of a LLM, following step by step tutorial that LLM gave me.
